Flow การทำงาน

ลำดับหลัก:
  1. ผู้ใช้เปิดเว็บ → index.php (Login)
  2. กรอก username+password → ck_login.php ตรวจสอบ
  3. Admin → dashboard.php / User → search.php
  4. ใช้งาน → search, userlist, Restore
  5. ออกจากระบบ → ck_logout.php → กลับ index.php
Flow ลืมรหัสผ่าน:
  1. index.php → กด "ลืมรหัสผ่าน?"
  2. forgot.php → กรอก username → ได้ลิงก์ reset
  3. reset_password.php?token=xxx → กรอกรหัสใหม่ → เสร็จ

ฟังก์ชัน PHP สำคัญ

ฟังก์ชันใช้ทำอะไร
session_start()เริ่ม session เก็บข้อมูลผู้ใช้ข้ามหน้า
password_hash()เข้ารหัสรหัสผ่านก่อนบันทึก

prepare()+bind_param()SQL ปลอดภัย ป้องกัน Injection

htmlspecialchars()ป้องกัน XSS
bin2hex(random_bytes())สร้าง token สุ่ม
json_encode()แปลงเป็น JSON

4. ck_login.php ตัวประมวลผล

หน้าที่: ตรวจสอบ username/password

คำอธิบาย: รับ POST จากฟอร์ม Login (1) ค้นหา username ด้วย Prepared Statement ป้องกัน SQL Injection (2) ใช้ password_verify() ตรวจรหัสผ่านกับ hash (3) ถ้าถูกต้องเก็บ session แล้ว Admin→dashboard.php (4) ถ้าผิด redirect กลับ

บรรทัด: 50 | ขนาด: 1313 bytes

<?php
include 'db.php';
session_start();

$username = $_POST['username'];
$password = $_POST['password'];

// เตรียมคำสั่ง SQL เพื่อตรวจสอบผู้ใช้
$setsql = $conn->prepare("SELECT id, username, password , role FROM users WHERE username = ?"); 

$setsql->bind_param("s", $username);

// ดำเนินการคำสั่ง SQL
$setsql->execute();

$result = $setsql->get_result();

if($result->num_rows === 1){

    $row  = $result->fetch_assoc();
    
    // ตรวจสอบรหัสผ่าน
    if(password_verify($password, $row['password'])) {
        $_SESSION['user_id']  = $row['id'];
        $_SESSION['username'] = $username;
        $_SESSION['role']     = $row['role'];


        if($row['role'] === 'admin'){
            header("Location: dashboard.php");
            exit();
        } else {
            echo "ไม่มีสิทธิ์เข้าใช้งาน";
        }
        exit();

    } else {
        echo "ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง";
    }
} else {
    header("Location: index.php");
}

// ปิดการเชื่อมต่อ
$setsql->close();
$conn->close();



?>
